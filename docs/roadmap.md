# v2 分阶段开发路线

每个阶段必须满足阶段门后才能进入下一阶段。阶段门关注可验证的产品能力，不以代码行数或模块数量作为完成标准。

## 阶段 0：基线与契约冻结

状态：**完成（文档基线）**

- 冻结首期范围：正交墙体、矩形房间、merge 房间、人工确认导入、CPU worker。
- 冻结 `SpatialModel v2` 的单位、坐标、对象 ID、revision、provenance 和 confidence。
- 定义几何、渲染、人工确认和失败阻断的验收指标。

阶段门：规格文档已评审；`orthogonal_v1` 范围、状态、revision、hash、坐标和容差提案已冻结；所有后续模块都能声明自己的输入 revision 和输出 artifact。模型完整实现不属于本阶段，进入阶段 1。

## 阶段 1：空间事实源

状态：**完成（MVP profile）**

目标：实现可持久化、可校验、可回溯的 `SpatialModel v2`。

- 完成正交墙体、房间、merge、门窗、家具实例和相机模型。
- 增加拓扑、单位、正值、有限数、引用、版本和 provenance 校验。
- 建立 fixture、序列化、反序列化和 revision 测试。

阶段门：同一模型序列化/反序列化后 hash 稳定；非法对象被阻断；不允许静默改坐标。阶段 1 只覆盖 `orthogonal_v1`，完整任意多边形拓扑属于后续 profile。

## 阶段 2：2D 编辑闭环

状态：**本地测试与独立复验通过，等待用户确认**

目标：先用本仓手工模型证明 2D 投影、编辑、保存、重载和版本切换无坐标漂移。

- 从 SpatialModel 派生正交墙、开口、merge 分组和家具平面。
- 数值编辑、家具拖动、撤销/重做；共享墙限制必须显式阻断。
- 不可变 revision、人工确认、历史恢复和并发写入冲突保护。

阶段门：小数坐标/尺寸保存重载一致；历史恢复不覆盖原版本；非法输入和旧页面写入不损坏事实源；桌面与移动端浏览器验收。

本次顺序修正落实已确认的“先手工模型垂直切片，再导入识别”，不在阶段 2 接入位图识别。

## 阶段 3：2D 到 3D 场景

状态：**独立验收通过，用户已确认**。

目标：从已确认平面生成可编辑 3D 场景。

- 实现墙体、地面、顶面、门窗和参数化家具简模。
- 输出固定相机下的基础渲染、深度、法线和实例 mask。
- 固定 `X east / Y south / Z up` 和 SVG Y 向下到右手 3D 的显式转换，见 `docs/decisions/0003-stage-3-coordinate-render-contract.md`。
- 固定 color/depth/normal/instance-mask 原始通道格式、实例 ID 表和渲染 manifest，见 `docs/specs/stage-3-cpu-3d.md`。
- 在独立 CPU worker 做耗时、内存、超时、确定性和并发测试；首期预算为默认 1024×768 P95 `<=30s`、单任务硬超时 `120s`、峰值 RSS `<=2GB`，最终以 spike ADR 冻结。
- 本阶段不接入位图、AI、实拍标定和自动家具布局。

阶段门：2D 坐标到 3D 再到相机投影无漂移（round-trip `0mm`、投影 `<=0.5px`）；同一输入重复渲染 hash 一致；每件家具有非空且唯一 instance mask；四类通道和 manifest 格式正确；CPU 预算、失败阻断和资源指标有真实 fixture 记录。阶段门未通过时停止后续 AI 和自动识别工作。

## 阶段 4：位图/PDF 导入与人工校核

状态：**实施中（首期 PNG/JPEG 位图）**。规格与边界见 `docs/specs/stage-4-ingest.md`，决策见 `docs/decisions/0004-stage-4-ingest.md`。

真实像素识别、工作台校核与 3D 的集成检查点已通过独立验收，实际交付契约见
`docs/specs/stage-4-integration.md`，结果见 `docs/stages/stage-4-integration-report.md`。
当前等待用户确认；完整阶段门仍未完成，禁止提前进入阶段 5。

阶段 4 的 ROI 候选生成与人工裁剪闭环已完成有界验收；当前继续在 4C1 做自由 ROI 与矩形人工描图，
仍未完成全屋拓扑。实现和边界见 `docs/specs/stage-4-manual-trace.md`、
`docs/test-reports/stage-4-manual-trace-acceptance.md`。

目标：把位图变成可确认的工程化平面草稿。

- 实现预处理、墙线/房间/门窗候选识别和尺寸读取。
- 输出 draft、来源及置信度；识别结果不自动变成工程事实。
- 复用 2D 校核工作台，经人工确认再进入 3D/布局。

阶段门：正交/merge 样本尺寸可核验；未确认、低置信度或拓扑错误不能进入精确布局。

## 阶段 5：家具精确落位

目标：让家具布局由求解器和几何规则决定。

- 支持真实尺寸、旋转、墙面吸附、碰撞、门洞/通道净空和遮挡。
- 自动布局只生成 proposal；审批后才形成 confirmed revision。
- 建立家具中心点误差、轮廓 IoU、越界和遮挡验收。

阶段门：目标房间内不存在未解释的越界、穿墙、阻门和 instance 丢失。

## 阶段 6：确定性渲染与几何验收

目标：从已审批场景稳定输出可回溯的基础图及几何证据。

- 固定相机 color、depth、normal、instance mask 与 artifact manifest。
- 校验投影位置、尺寸、遮挡、instance 完整性和背景。
- 验证 CPU worker 的可复现性、耗时、内存及失败状态。

阶段门：不依赖 AI 即能产出几何可信的基础渲染；不一致不能伪装成功。

## 阶段 7：受控照片级增强

目标：在几何正确的基础图上增加照片质感。

- 将基础渲染、depth、normal、mask 和材质层交给 AI 增强。
- 精确模式禁止模型修改墙体、门窗、家具位置、尺寸和遮挡。
- 保存基础图、增强图、prompt、模型和输入 hash。

阶段门：增强图通过几何一致性和背景变化阈值；失败时保留基础渲染，不伪装成功。

## 阶段 8：生产化与扩展

目标：扩展到多项目、多房间和更多输入类型。

- API、权限、任务队列、对象存储、审计和观测完善。
- 按项目灰度发布，支持重试、幂等和回滚。
- 在数据驱动验证后再考虑斜墙、任意多边形、LiDAR 和真实资产库。

阶段门：生产指标达到发布阈值，且所有核心 artifact 可追溯、可重现、可清理。

## 停止条件

阶段 3 若无法证明 2D/3D/相机投影无漂移，停止后续 AI 和自动识别工作，先修正空间模型或渲染方案。

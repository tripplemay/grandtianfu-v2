# 阶段 4D：复杂宣传页的多房间位图候选识别

状态：独立验收通过，用户验收通过（2026-09-08）。

## 问题

阶段 4 的严格闭合矩形识别适合干净的工程平面图，但宣传页通常同时包含标题、尺寸链、家具线稿、文字和门洞。门洞会打断内部墙线，导致整张图只形成一个可闭合矩形，不能作为多房间候选输入。

## 本批次范围

- 当全图严格识别只得到一个房间且存在高排名户型 ROI 时，在 ROI 内执行第二次结构线解析。
- 通过长正交线构造墙体掩膜，提取互不相交的房间大小自由空间组件。
- 输出多个 `room`/`wall` 候选，所有对象带 `provenance=roi_structural_component`、低置信度和 `needs_review=true`。
- 保留 `partial_plan_requires_manual_trace` 阻断；多房间候选不能绕过人工描图、拓扑审核或确认门。
- 在 preprocessing manifest 中记录 `room_detection.mode` 和候选数量，便于回放和排错。

## 非目标与限制

- 不声称完成自动房间语义分类、门窗分类、尺寸线关联或精确拓扑恢复。
- 组件可能包含合并房间、阳台或走道，必须在人工拓扑审核中拆分或合并。
- 组件边界是候选几何，不是测量事实；不能直接进入精确家具布局和照片级渲染。

## 阶段门

1. 干净单房间和双房间 fixture 的既有精确结果不回归。
2. 带标题块、家具线和门洞的多房间 fixture 输出至少两个候选，且低置信度、来源和阻断证据完整。
3. 用户提供的 3000x3499 JPEG 在 CPU worker 运行后不再只输出一个房间；结果可重复，并保留人工确认阻断。
4. 全量 Python、ruff、前端构建和 ingest E2E 回归通过。

# ADR 0001: Greenfield v2 空间系统

## 状态

Accepted，2026-09-06。

## 背景

旧系统的实拍主链路把结构化布局压缩成自然语言，再交给整图模型重绘。它没有以可验证的 3D 场景作为事实源，继续修补会把概念预览语义带入生产系统。

当前生产资产属于测试资产，不要求迁移。因此可以建立不兼容旧运行时契约的 v2，并把旧仓库冻结为只读参考。

## 决策

建立独立仓库 `grandtianfu-v2`，从 `SpatialModel v2` 开始重建：

1. 位图/PDF/CAD/扫描先进入带置信度的结构化平面模型。
2. 平面模型确定性生成可编辑 3D 场景。
3. 家具位置、尺寸、旋转和遮挡由场景模型与求解器决定。
4. 基础图由确定性渲染器生成。
5. LLM 仅在 mask/depth/normal 等约束下做材质、灯光和照片质感增强。

旧仓库不作为 v2 的运行时依赖；旧数据不迁移。旧代码和产物只用于需求回放、失败分类和离线回归。

## 不在本决策内锁定的内容

- Blender、Three.js、Unreal 或其他渲染器的最终选择。
- PostgreSQL、对象存储和队列的具体供应商。
- 位图识别使用的 CV/ML 模型。
- 真实家具资产库的供应链和授权方式。

这些选择必须在单房间 spike 中以落位误差、渲染质量、成本和部署约束评估后决定。

## 退出条件

如果手工构建的单房间 3D 垂直切片无法稳定证明“2D 坐标 -> 3D -> 相机投影”无漂移，则停止扩展 AI 和自动识别，先修正空间模型或渲染方案。

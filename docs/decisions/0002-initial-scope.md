# ADR 0002: 首期范围与阶段门

## 状态

Accepted，2026-09-06。

## 决策

首期只支持正交墙体、矩形房间和 merge 房间。位图解析采用“AI 草稿 + 人工确认”流程。服务端渲染采用 CPU worker 优先，渲染器选型在单房间 spike 中确定。

## 原因

首期要验证的是空间事实源、家具精确落位和确定性相机投影。斜墙、任意多边形、自动无审查导入和 GPU 渲染会同时引入新的几何、产品和部署变量，应该在核心链路通过后再增加。

## 阶段门原则

每一阶段都必须有可重复的 fixture、自动化验证和明确失败状态。阶段门未通过时，不扩大输入类型、房间规模或 AI 能力。

# ADR 0005：宣传页户型区域 ROI 候选

## 状态

Proposed，2026-09-07。仅用于阶段 4 的导入证据，不扩大 `orthogonal_v1` 的事实范围。

## 背景

户型图经常被放在带有品牌、标题、面积、尺寸标注和装饰纹理的宣传页中。若直接
在整张图片上寻找闭合矩形，尺寸线和页面装饰可能被配对成伪墙；若把识别到的局部
矩形当作整套户型，又会把缺失区域静默变成事实。此前真实宣传页复现得到一个右侧
局部矩形，同时有 31 条未归属长线，必须保留这一“局部但不完整”的状态。

## 决策

1. 在闭合矩形识别前，基于二值图提取短水平/垂直长线掩膜，并使用小尺度闭合与膨胀
   连接同一图纸区域。连通组件只生成 `floorplan_roi` 候选，不生成 room/wall/opening。
2. 每个候选保存 `evidence_bbox`、暗像素比例、正交线像素比例、相交长线数量、参数、
   算法来源和稳定排名。候选最多保留 8 个，所有候选 `needs_review=true`、`confidence<0.90`
   且 `selection=manual_crop_or_trace`。
3. ROI 边界只能作为人工裁剪、局部追踪和叠加查看的建议。ROI 内仍需独立执行墙体、房间、
   开口和尺寸识别；ROI 外的线不能被丢弃，继续写入 `unassigned_lines` 并维持
   `partial_plan_requires_manual_trace` 硬阻断。
4. ROI 算法不使用 OCR 文本、不使用图片外框、不推断比例尺，不改变现有模型坐标和模型
   `rooms`、`walls`、`openings` 集合。重复运行的候选 JSON 必须保持确定性。

## 证据与限制

暗像素可帮助定位图纸，但品牌字标、尺寸链和深色装饰也会形成组件；正交线比例和
相交长线数仅用于排序，不能解释为识别正确率。候选 bbox 不承担墙体边界语义，
不得用于直接确认、3D 或家具布局。真实宣传页仍需要用户人工选择/裁剪主户型，并
补画缺失边界后才能进入完整拓扑识别。

## 后续进入条件

- 使用获授权的真实户型标注集评估 ROI 召回、误选率、面积覆盖率和 CPU 预算；合成矩形
  只能验证确定性和不伪造几何。
- 在 UI 提供 ROI 候选叠加、人工裁剪/旋转和“保留原图证据”的操作，裁剪生成新派生
  artifact，绝不覆盖原始上传。
- ROI 内外的线段、OCR 尺寸和开口候选需要保持坐标变换记录，以便最终追溯原始 SHA-256。

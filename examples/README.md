# 位图闭环验收样例

`synthetic-room.png` 是由 `make_bitmap_sample.py` 生成的 **合成线稿**，不是实测户型，
不能用于声称真实识别准确率。重复生成：`uv run python examples/make_bitmap_sample.py`。

在工作台导入这张图，显式输入 `10 mm/px`：

- 图像 400 x 300 px；墙带 5 px，对应候选墙厚 50 mm。
- 房间中心线边界应约为 `(420, 320, 3160, 2360) mm`，不是图片外框。
- 无门窗、家具和相机。墙高 2800 mm 为未测默认值，核验界面必须显示来源警告。
- 切换源图对照，检查墙线与黑线一致；修改墙高后保存为新草稿，勾选审核清单才能确认。
- 测试相机可显式输入位置 `(1000, 1000, 1800)`，目标 `(2200, 2000, 700)`，
  单位 mm。这是为查看合成房间选取的相机，不来自位图识别。
- 相机保存后重新保存草稿并审核确认，再生成 3D；核对版本与源 hash。修改后必须重新审核。

完整 API/异常验收由 `uv run pytest -q` 和 `uv run pytest tests/e2e -q` 执行。
